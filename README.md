## Overview

AXION is a modern fitness and coaching landing experience built with Next.js, designed around a high-performance brand aesthetic. The product emphasizes personalized training, measurable outcomes, and premium client support — all presented in a dark, cinematic interface that feels as strong as the transformation it promises.

From tailored workouts to structured nutrition guidance and elite coaching, AXION helps clients move from intention to execution.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the app in your browser:

```text
http://localhost:3000
```

---

## Available Scripts

npm run build   # create production build
npm run start   # run production server
